# Security policy

## Supported version

Security fixes are currently provided for TeachLens 1.x.

## Reporting a vulnerability

Please do not publish a security vulnerability as a public issue. Email **thanh.vuh@gmail.com** with:

- the affected TeachLens version;
- steps to reproduce the issue;
- its possible impact; and
- any suggested mitigation.

You should receive an acknowledgement within seven days. No sensitive system information is required beyond what is necessary to reproduce the issue.

## Privacy baseline

TeachLens does not include telemetry, analytics, advertising, update checks or network communication. It does not request administrator privileges. Local preferences are stored in `%LOCALAPPDATA%\TeachLens\settings.ini`.
